# המורה שלי לאנגלית

מסלול ללימוד אנגלית מדוברת, מאפס ועד שיחה, עם מורה AI שמדבר איתך בקול, מתקן ומסביר בעברית.

## הפעלה

פעם ראשונה: מעתיקים את `.env.example` לקובץ `.env` ומכניסים מפתח Gemini (חינמי: https://aistudio.google.com/apikey).

בכל פעם, מתוך התיקייה `bot`:

```
npm start
```

ואז פותחים ב-**Chrome** או **Edge** את http://localhost:3333 ומאשרים גישה למיקרופון.

## איך לומדים (15-20 דקות ביום)

1. **אבחון** (פעם אחת, 5 דקות): מילים ומשפט קצר בדיבור. קובע את הרמה ואת מידת העזרה בעברית.
2. **חזרה**: מה שלמדת חוזר בזמן הנכון (יום, 3 ימים, שבוע, ואז פחות ופחות). מה שלא ידעת חוזר מחר.
3. **שיעור אחד**: פתיחה, מילים, משפטים מוכנים, בדיקה (כולל שמיעה), תרגול (עברית → אנגלית בקול), משימת שיחה, סיכום.
4. **שיחה חופשית**: כשיש כוח. תיקונים ומילים חדשות נכנסים למחברת החזרה.

| כפתור | מה הוא עושה |
|---|---|
| 🔊 | משמיע. את המהירות משנים למעלה בדף |
| 🎙️ | בדיקת הגייה: לוחצים, אומרים, לוחצים שוב |
| 🎤 | מדברים במקום לכתוב (באנגלית או בעברית) |
| 💡 | רמז כשנתקעים |

## מה יש עכשיו, ומה עוד לא

- **יש:** 10 שיעורים של רמה A1 (ברכות, "לא הבנתי", עליי, שעות, משפחה, אוכל, היום שלי, הכוונה בעיר, קניות, תחביבים).
- **עוד לא:** רמות A2 ומעלה (שלב 2).
- **קול:** קול טבעי של Gemini (בוחרים קול בראש הדף). כל משפט נוצר פעם אחת ונשמר ב-`data/tts`, ומשפטי השיעור נטענים מראש ברקע. בשיחה הקול מגיע כ-2-3 שניות אחרי הטקסט. במפתח החינמי יש מכסה קטנה לקול, אז בפועל הקול נוצר כמעט תמיד מהמפתח בתשלום. "קול הדפדפן" הוא חלופה מיידית וחינמית, אבל רובוטית.
- **הגייה:** הבדיקה נעשית על ידי AI ולוקחת כ-7-10 שניות. היא תופסת טעויות נפוצות (th, v/w) ומשפט שונה מהמבוקש, אבל זה מאמן, לא ציון מדויק.
- **טלפון:** כרגע רק מהמחשב. מהטלפון הדפדפן לא מאפשר מיקרופון בכתובת מקומית לא מאובטחת.
- **פרטיות:** השיחות וההקלטות נשלחות ל-Google Gemini. ההתקדמות נשמרת רק אצלך: `data/progress.json`.

## למפתחים

- `public/curriculum.js`: תוכן השיעורים (קבוע, לא נוצר על ידי AI).
- `public/learning.js`: חזרה מרווחת, רצף, בדיקת תשובות, אבחון. ללא DOM, משותף לדפדפן ולבדיקות.
- `public/app.js`: המסכים. `server.js`: התקדמות, Gemini (מפתח חינמי ואז בתשלום, מגבלת זמן, השבתה זמנית של מפתח שנכשל).
- בדיקות: `npm test`.
